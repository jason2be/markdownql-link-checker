# Contributing

Contributions are welcome through GitHub issues and pull requests.

Before opening a pull request:

1. Keep the JavaScript runtime free of direct filesystem, network, native editor, and window access.
2. Declare every module, resource, contribution, and grant in `manifest.json`.
3. Preserve `on-command` activation and zero work while disabled.
4. Update the changelog and evolution evidence when package bytes change.
5. Validate the package with the pinned public SDK command in `README.md`.

Do not copy code from the behavior-reference repository unless it later publishes a compatible license and the contribution separately documents the new provenance and legal review.
